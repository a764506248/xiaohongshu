# 图片与小红书内容包执行计划

## 1. 启动条件

只有第一期 MVP 验收通过后才启动本计划。

## 2. 目标

把已审核文章转换成可直接用于小红书的图文内容包，包括标题、正文、标签和 3～5 张图片。

## 3. BE-07：视觉页面脚本

### 流程

```text
已审核文章
→ 提取核心观点
→ 规划 3～5 个页面
→ 生成每页短文案
→ 校验字数与顺序
```

每页至少包含：

- 页面标题
- 精简正文
- 页面用途
- 视觉描述
- 布局模板标识

## 4. BE-08：图片生成能力

### 工作范围

- 定义 `ImageProvider` 接口。
- 生成背景或插图。
- 中文文字由模板排版层渲染。
- 保存生成参数、提供商任务 ID 和图片版本。
- 支持单张重生成和人工图片替换。

### 存储原则

- 图片文件进入对象存储。
- PostgreSQL 只保存地址、哈希、尺寸、提示词和版本信息。
- 不在 LangGraph state 中保存图片二进制数据。

## 5. FE-06：图片编辑与预览

### 功能

- 查看 3～5 张图片。
- 单张重生成。
- 只修改页面文字。
- 上传人工图片替换。
- 调整图片顺序。
- 切换视觉模板。

## 6. BE-09：小红书内容适配器

定义统一的 `ChannelAdapter`，小红书作为第一个实现：

```text
validate()
transform()
preview()
export()
```

输出内容包：

- 标题
- 正文
- 话题标签
- 封面
- 3～5 张图片
- 内容校验结果

本期只负责预览和导出，不做自动发布。

## 7. FE-07：小红书内容包页面

- 模拟平台预览。
- 编辑标题、正文和标签。
- 下载图片。
- 复制正文。
- 导出完整内容包。

## 8. IT-06：第二期联调验收

- 审核通过的文章可以生成页面脚本。
- 可以生成并保存 3～5 张图片。
- 任意单张可独立重新生成。
- 内容包包含可用标题、正文、标签和图片。
- 图片失败不会破坏文章和其他已完成图片。
- 不依赖自动发布权限即可完成运营交付。
