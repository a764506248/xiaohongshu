# 多平台发布与数据运营路线图

本文件记录第三至第五期的实现边界。三个阶段的本地基座已经完成；真实平台连接器仍需开放平台凭证。

## 当前入口

- 多平台内容：任务审核完成后点击“进入多平台运营”。
- 发布审批与排期：前端 `/publishing`，后端 `/api/v1/publish-jobs`。
- 数据运营：前端 `/analytics`，后端 `/api/v1/analytics/summary`。
- 完整接口参数与响应说明：`http://localhost:8000/docs`。

## 1. 第三期：微信公众号与多平台内容

### 后端任务

- BE-10：完善统一 `ChannelAdapter`。
- BE-11：微信公众号内容转换器。
- BE-12：富文本正文和封面处理。
- BE-13：平台账号安全配置。
- BE-14：手动发布状态记录。

### 前端任务

- FE-08：平台内容切换预览。
- FE-09：公众号富文本预览。
- FE-10：平台账号配置页面。
- FE-11：手动发布状态管理。

### 联调验收

- 同一篇母稿可生成不同平台版本。
- 修改平台版本不会覆盖文章母稿。
- 新增平台不需要修改文章生成工作流。

## 2. 第四期：发布自动化

### 后端任务

- BE-15：发布任务模型。
- BE-16：预约发布调度。
- BE-17：发布前人工审批。
- BE-18：平台发布实现。
- BE-19：幂等、重试和失败补偿。
- BE-20：平台回调与状态同步。

### 前端任务

- FE-12：发布任务页面。
- FE-13：发布前审批页面。
- FE-14：内容日历。
- FE-15：失败任务处理页面。

### 安全边界

- 发布凭证加密保存。
- 默认要求发布前审批。
- 所有发布尝试保留审计记录。
- 工作流恢复不得导致重复发布。

## 3. 第五期：数据运营闭环

### 后端任务

- BE-21：定义 `MetricCollector`。
- BE-22：平台指标采集。
- BE-23：内容表现评分。
- BE-24：用户偏好信号更新。
- BE-25：历史选题重复度检测。
- BE-26：模型成本和效果统计。

### 前端任务

- FE-16：内容表现看板。
- FE-17：选题和内容对比。
- FE-18：模型成本看板。
- FE-19：提示词版本与实验页面。

### 数据闭环

```text
平台指标
→ 内容表现评分
→ 更新用户偏好信号
→ 影响下一轮选题排序
→ 保留人工最终决策
```

## 4. 后期能力候选项

- 多组织和多品牌
- 角色权限和分级审核
- 团队协作与评论
- 知识库和事实引用
- 热点信息检索
- 短视频脚本与视频生成
- 移动端审核

这些能力应按真实业务需求立项，不应提前加入第一期工程。
