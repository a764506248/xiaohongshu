## 推荐执行顺序

```text
01 基础工程
  ↓
02 内容任务与选题
  ↓
03 文案生成与审核
  ↓
第一期 MVP 验收
  ↓
04 图片与小红书内容包
  ↓
05 多平台发布与数据运营
```

## 单项执行规则

- 一次只执行一个编号任务，例如 `BE-02` 或 `FE-03`。
- 后端接口完成并自测后，再实现依赖它的前端任务。
- 每组前后端任务后必须执行对应的 `IT` 联调任务。
- 未达到验收标准，不进入下一个功能阶段。
- 后续功能通过既定扩展接口接入，避免提前实现暂不需要的模块。
